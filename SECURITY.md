# Security Policy

## Supported versions

Only the latest release of **PaperPlane Mail Test** receives security fixes. Please update to the latest version before reporting an issue.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately via GitHub: [**Report a vulnerability**](https://github.com/paperplanefactory/paperplane-mail-test/security/advisories/new) (you need to be signed in to GitHub). The report is visible only to the maintainers.

Please include:

- the plugin version;
- a description of the issue and its impact;
- the steps to reproduce it.

## What to expect

- Acknowledgement within 5 working days.
- A fix released as soon as possible, depending on severity.
- Credit in the release notes, if you wish.
