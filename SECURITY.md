# Security Policy

## Supported versions

Only the latest release of **PaperPlane Mail Test** receives security fixes. Please update to the latest version before reporting an issue.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately via GitHub: open the [**Security** tab](https://github.com/paperplanefactory/paperplane-mail-test/security) of this repository and click **Report a vulnerability**.

Please include:

- the plugin version;
- a description of the issue and its impact;
- the steps to reproduce it.

## What to expect

- Acknowledgement within 5 working days.
- A fix released as soon as possible, depending on severity.
- Credit in the release notes, if you wish.
